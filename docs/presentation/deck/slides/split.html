2 · 아키텍처: LLM과 코드의 역할

LLM이 맡은 부분과 코드가 맡은 부분

하는 일LLM일반 코드
추출글에서 기기·버전·증상·재현 순서 뽑기빠진 정보 계산, 태그로 데이터 보호
분류버그·문의·개선 요청 판단과 근거대표 종류를 여러 라벨에 포함
이슈 연결검색어 정하고 맞는 이슈 고르기검색 결과에 있던 번호인지, 수정 버전 이상인지, 아이폰인지 확인
점수우선순위, 근거, 제보자에게 할 질문완성도 1점·2점 계산
챗봇대화 이해, 도구 선택, 답 쓰기내 제보만 조회, 재분석과 담당 변경 검사

그 밖의 접수·저장, 담당 배정, 요청 횟수 제한은 모두 코드가 맡음

AI는 글을 이해하고 판단하는 일을, 코드는 규칙이 정해진 일과 확인을 맡습니다.
