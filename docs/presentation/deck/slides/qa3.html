없는 기능을 버그로 보는 문제는 어떻게 줄이나?

지금

분류 지시에 앱의 정상 동작 9가지를 적었다. 목록에 있는 동작을 묻는 것만 문의로 보고, 목록 밖은 고장 가능성이 있으면 버그로 본다

일부러 고른 쪽

버그를 놓치는 쪽이 더 위험하다고 판단했다. 250건에서 버그를 놓친 건수 0·0·1, 버그가 아닌 것을 버그로 본 건수 7·5·5

줄이는 방법

앱에 있는 기능 목록을 제품 담당자가 확정해 넣고, 진짜 버그를 놓치지 않는지 새 사례로 다시 잰다

실제로 겪은 부작용 정상 동작 규칙을 넓게 쓰자 진짜 버그 3건을 문의로 보냈다 (V2-Run-09). 규칙을 “목록에 있는 동작”으로 좁혀 0건으로 되돌렸다 (V2-Run-10)

250건 · V3-Run-15 3회 · 정상 동작 목록과 FAQ는 함께 바꿔야 함

지금은 분류 지시에 앱의 정상 동작 9가지를 적어 두고, 목록 밖은 고장 가능성이 있으면 버그로 봅니다. 버그를 놓치는 쪽이 더 위험해서 일부러 그렇게 했고, 250건에서 버그를 놓친 건 0, 0, 1건, 버그가 아닌 걸 버그로 본 건 7, 5, 5건입니다. 줄이려면 앱에 있는 기능 목록을 제품 담당자가 확정해 넣어야 합니다. 규칙을 넓혔다가 진짜 버그 3건을 놓친 적이 있어서, 바꿀 때마다 새 사례로 다시 재야 합니다.
