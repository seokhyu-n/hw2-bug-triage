2 · 아키텍처: 주요 설계 1개

AI가 고르고, 코드가 확인한다

문제

AI는 도구에 없는 이슈 번호를 그럴듯하게 쓸 수 있다. 같은 제보에도 점수가 흔들린다 (정보가 다 있는 제보에 3번 모두 완성도 1점)

선택

이슈 번호는 도구가 돌려준 것만 연결한다. 완성도 1점·2점은 앱 버전·OS 버전·재현 순서가 있는지로 코드가 계산한다

이유

틀린 연결은 새 버그를 “이미 아는 문제”로 닫아 버린다. 규칙으로 답이 정해지는 일은 코드가 정확하다: 완성도 오차 0.128 → 0.043

글을 이해하는 판단은 AI에게, 규칙으로 정해지는 일은 코드에게

완성도 오차: 250건, 코드 계산 전 → 후, 3회 평균

주요 설계 하나는 AI가 고르고 코드가 확인한다는 것입니다. 문제는 AI가 도구에 없는 이슈 번호를 그럴듯하게 쓸 수 있고, 같은 제보에도 점수가 흔들린다는 것입니다. 그래서 이슈 번호는 도구가 돌려준 것만 연결하고, 완성도 1점과 2점은 코드가 계산하게 했습니다. 틀린 연결은 새 버그를 이미 아는 문제로 닫아 버리고, 규칙으로 정해지는 일은 코드가 정확하기 때문입니다. 250건 완성도 오차가 0.128에서 0.043으로 줄었습니다.
