1 · 선택한 과제와 이유

개발팀 업무를 고른 이유: 내가 만든 앱이라 버그를 판단할 수 있다

문제

제보 정리는 사람 손이 많이 든다

들어온 글을 읽고 버그인지 문의인지 나누고, 빠진 정보를 묻고, 급한 순서를 정하고, 이미 아는 문제인지 찾아야 한다

선택

과제 4개 중 개발팀 업무

소재는 전공 수업에서 3명이 만든 안드로이드 러닝 앱 RunBuddy

이유

실제로 나올 버그를 안다

예: 알려진 이슈 ISSUE-04(거리가 짧게 기록됨)는 앱 코드가 30m 넘게 튄 위치를 버리는 부분을 보고 만들었다

앱 코드 근거: RunningRepository.kt 139행 · 알려진 이슈 목록은 더미 데이터

과제 네 개 중 개발팀 업무를 골랐습니다. 개발팀은 들어온 제보를 읽고 버그인지 문의인지 나누고, 빠진 정보를 묻고, 급한 순서를 정하고, 이미 아는 문제인지 찾아야 합니다. 소재는 제가 팀으로 만든 러닝 앱 RunBuddy입니다. 직접 만든 앱이라 어떤 버그가 실제로 나올지 판단할 수 있었습니다. 예를 들어 ISSUE-04, 거리가 짧게 기록되는 이슈는 앱 코드가 30미터 넘게 튄 위치를 버리는 부분을 보고 만들었습니다.
