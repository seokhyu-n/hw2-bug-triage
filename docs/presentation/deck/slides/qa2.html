도구가 돌려준 후보 중 잘못된 이슈를 AI가 고르면?

코드가 막는 것

  • 도구 결과에 없던 번호
  • 이미 고친 버전에서 난 제보 (재발은 새 신고로)
  • 아이폰 제보 ↔ 안드로이드 전용 이슈

코드가 못 막는 것

  • 후보 안에서 증상이 다른 이슈
  • 영향 OS 범위 밖의 이슈

도구는 키워드가 맞는 이슈를 최대 5건 돌려주고, OS·버전은 순서만 바꾼다

지금 관리하는 방법

  • 규칙: 증상이 다르면 기능이 같아도 연결하지 않음
  • 측정: 이슈 연결 250건 0.993, 새 100건 1.000
  • 개발자가 화면에서 연결을 바꿀 수 있음

함정 사례: 반대 증상 E-004(거리가 길게), OS 범위 밖 E-009(안드로이드 10) · 다음 단계: 영향 OS 범위도 코드로 확인

코드는 도구에 없던 번호, 이미 고친 버전의 재발, 아이폰과 안드로이드 전용 이슈의 연결을 막습니다. 하지만 후보 안에서 증상이 다른 이슈나 영향 OS 범위 밖의 이슈를 고르는 것은 코드가 막지 못합니다. 지금은 프롬프트 규칙과 평가로 관리하고, 이슈 연결 정확도는 250건 0.993, 새 100건 1.000입니다. 다음 단계로 영향 OS 범위도 코드로 확인하려고 합니다.
