4 · 결과 요약: 점수 기준

우선순위와 완성도

우선순위 = 얼마나 급한가

등급기준
P1앱이 꺼짐, 로그인 불가, 저장된 기록이 사라짐
P2핵심 기능이 틀림(거리·경로가 크게 틀림, 기록 저장이 안 됨)
P3우회할 수 있거나 부가 기능 문제(음성 안내, 러닝 카드)
P4오타 같은 사소한 문제, 일반 문의와 개선 요청

완성도 = 정보가 얼마나 충분한가

점수기준 (버그일 때만)
0점무슨 문제인지 알 수 없음(“앱이 이상해요”)
1점문제는 알겠는데 앱 버전·OS 버전·재현 방법 중 빠진 게 있음
2점셋 다 있음(개발자가 바로 따라 해 볼 수 있음)

우선순위는 AI가 근거를 먼저 쓰고 판단 · 완성도는 0점은 AI, 1점과 2점은 코드

우선순위는 급한 정도, 완성도는 정보가 충분한 정도입니다. 예: “자꾸 튕겨요”는 급하니 P1이지만, 버전과 재현 방법이 없어 완성도는 1점입니다. 급한 것과 정보가 충분한 것은 별개입니다. 이미 고친 문제가 일부 구형 기기에만 생기면 P1을 P2로 낮춥니다.
