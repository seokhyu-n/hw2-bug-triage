부록 · 예상 질문 1

완성도 정답도 같은 규칙이면, 오차가 줄어든 것은 무엇을 뜻하나?

뜻하는 것

AI가 규칙을 일관되게 지키지 못하던 문제를 코드가 없앴다는 것. 정보가 다 있는데 1점을 주던 E-131 같은 경우가 사라졌다

뜻하지 않는 것

AI의 판단이 좋아졌다는 뜻은 아니다. 0점(증상이 불명확)은 여전히 AI가 정하고, 추출이 틀리면 완성도도 함께 틀린다

확인할 방법

사람이 매긴 완성도 정답으로 다시 재기 (지금 사람 검토 34건) · 실제 제보에서 개발자가 되물은 비율과 비교

완성도 오차, 튜닝 전 → 지금: 250건 0.120 → 0.043, 새 100건 0.147 → 0.018 (각 3회 평균) · 두 세트 모두 정답을 같은 규칙으로 만듦

완성도 오차가 줄어든 것은 AI가 규칙을 일관되게 지키지 못하던 문제를 코드가 없앴다는 뜻입니다. AI의 판단이 좋아졌다는 뜻은 아닙니다. 0점은 여전히 AI가 정하고, 추출이 틀리면 완성도도 함께 틀립니다. 확인하려면 사람이 매긴 정답으로 다시 재야 합니다.
